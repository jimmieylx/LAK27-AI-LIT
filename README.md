# AI-LIT @ LAK27 — official workshop microsite source

**AI Literacy in Action for Human–AI Collaboration and Agency**  
**Second International Workshop on Advancing AI Literacy with Learning Analytics (AI-LIT)**

This independent public website supports the 17th International Conference on Learning Analytics & Knowledge (LAK27), Recife, Brazil, with pre-conference workshops on 8–9 March 2027. The exact day, room and keynote for AI-LIT will be added when confirmed.

## Website

**https://jimmieylx.github.io/LAK27-AI-LIT/**

## Enabling GitHub Pages

The repository administrator needs to enable hosting once:

1. Go to **[Settings → Pages](https://github.com/jimmieylx/LAK27-AI-LIT/settings/pages)**.
2. In **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the **main** branch and **/(root)** folder, then click **Save**.
4. GitHub will automatically publish the static website. Later commits to `main` will deploy updates.

No build tools or API keys are required. The website consists of HTML, CSS, one tiny JavaScript file and SVG assets.

## Project continuity

This site follows the content architecture of the [AI-LIT workshop at LAK26](https://sites.google.com/monash.edu/ai-lit-lak/home) and the LAK27 workshop proposal submitted as #565. The visual identity uses Monash University’s official primary colour Monash Blue (`#006DAE`), supported by white, neutral grey, and restrained tertiary-blue accents (`#ABF5F9`, `#285AFF`, `#121256`). This is an independently maintained workshop website and does not use an official Monash University logo or imply institutional endorsement.
